Block Components
----------------

| Component                             | Existing | Comments                  |
| ------------------------------------- | -------- | ------------------------- |
| Type (proto, method, multi, sub, etc) | Exists   | Add predicate/law         |
| Name (for proto/multi/whatever)       | Exists   |                           |
| Input Signature                       | Exists   |                           |
| Return Signature                      | New      | If names are specified, then these are available in the block, and whatever they're set to is used in the return value.  They're also passed in from outside, so that we can eg. pass in a table that will hold the return values |
| Match Block                           | Newish   | Only used in grammars.  If Match block fails, then the return value is false.  If True, then it returns the return value of the action block (if any), otherwise True |
| Action Block                          | Exists   | The block of any callable |

Also useful (maybe for predicates?): https://docs.raku.org/type/Metamodel/ClassHOW
